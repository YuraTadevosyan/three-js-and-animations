Qwik · WebGPU · WGSL · CSS scroll-driven animations · no images, no UI kits

1980DOS

The command line. Eighty columns, twenty-five rows, and a cursor that waits for you to already know the right words.

Click the screen and type HELP, EDIT, VIEW LAKE.PCX, PLAY SONG.MUS or SNAKE.

1995Windows 95

The desktop metaphor goes mainstream. Windows, icons, a Start button, and the idea that you could find things by looking instead of remembering.

Paint on the lake: it stays painted in every decade after this. Play song.mid, then scroll on and keep listening.

2005Web 2.0

The browser becomes the app. Glossy gradients, rounded corners, reflections, beta badges and AJAX spinners. Everything wants to be clicked.

Update your status (it rewrites the note), press play on notr radio, rate the photo.

2015Material Design

Gloss is flattened into paper and ink. Bold colour, a strict grid, and shadows that mean elevation rather than decoration. Motion explains what just happened.

Tap anything for an ink ripple. Archive a message, then UNDO.

2025Glassmorphism

Depth returns as light instead of texture: translucent panels, background blur and specular edges floating over vivid colour.

Move the pointer across the panels. Turn Wi-Fi off, then see what 2040 says.

2040Sci-Fi UI

Speculative. The screen dissolves into space: data as light, an interface you talk to, and a photo you can walk around.

Drag the hologram. Ask NEXUS to “play the song”. Answer Mom.

About this page

The Evolution of UI

Sixty years of interface design, rebuilt from scratch on one page. No screenshots and no emulators: every decade is drawn by today’s web platform, and every one of them works.

Built with

Framework & build

  • Qwik1.20

    Resumable components. The whole page arrives as HTML; a handler’s code downloads the first time you use it.

  • Qwik City1.20

    Static site generation: the one route is rendered at build time, all six eras included.

  • Vite7.3

    Dev server and build. A small plugin also emits lake.svg, generated from the same code that draws it in the browser.

  • TypeScript5.8

    Strict, everywhere: components, the terminal, the audio engine, the tests.

  • Tailwind CSS3.4

    Tokens for the museum chrome only. Each era has its own hand-written stylesheet.

Graphics

  • WebGPU

    One device, two canvases: the 1980 CRT and the 2040 hologram.

  • WGSL

    Three hand-written shaders: the CRT, the hologram’s instanced sprites, and a compute shader for its spring physics.

  • Canvas 2D

    The 80×25 text mode under the CRT, Paint, 16-colour dithering, and the hologram when WebGPU isn’t there.

  • SVG

    Every Windows 95 icon, Minesweeper’s counters, and the lake photo itself, generated from a seed.

Motion & style

  • CSS scroll-driven animations

    A view timeline drives one number, --t, from 0 to 7. Every transition on the page is a calc() of it.

  • @property

    Typed custom properties. --t is a <number> so it can animate; the year counter is an <integer> fed to a CSS counter.

  • color-mix(), clamp(), sin()

    The Web 2.0 gloss draining into Material indigo, the CRT tearing, every eased fade.

  • clip-path, backdrop-filter

    The web seen through Internet Explorer, Material’s ink flood, and 2025’s frosted glass.

Sound & voice

  • Web Audio API

    Everything you hear is synthesised: one song in six arrangements, every click, beep and chime.

  • Web Speech API

    Talk to NEXUS in 2040, and hear it answer.

Platform

  • Pointer Events

    Dragging windows, painting, orbiting the hologram, pushing its points, the light on the glass.

  • <dialog>

    This panel: focus, Esc and the backdrop come with the element.

  • localStorage

    Your note, your painting, your read messages and switches, between visits.

Checked without a browser

  • esbuild + Node0.28

    npm test: the terminal, Minesweeper, the audio engine on a strict fake AudioContext, the hologram’s framing.

  • Dawn

    Chrome’s WebGPU implementation, run from Node to compile and execute every shader.

  • ESLint + eslint-plugin-qwik9.39

    Catches values a Qwik handler can’t serialise, before the browser would.

Each decade, underneath

1980DOS
Text mode on Canvas 2D → WGSL CRT shader on WebGPU (or a DOM <pre>), a square-wave PC speaker
1995Windows 95
Qwik components, a Pointer Events window manager, Paint on Canvas 2D with Bayer dithering, SVG icons, FM synthesis
2005Web 2.0
Gradients, box-reflect and clip-path to the IE viewport; color-mix() drains the gloss
2015Material
A growing clip-path circle(), shadows as elevation, ripples from Pointer Events
2025Glass
backdrop-filter over the real page behind it, pointer-tracked radial light, 3D transforms
2040Sci-fi UI
WebGPU compute + instanced rendering, Web Speech, a Canvas 2D fallback

Built without UI kits · animation libraries · 3D engines · math libraries · image files · audio files.
